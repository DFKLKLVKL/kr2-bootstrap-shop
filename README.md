# kr2-bootstrap-shop

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Учебный интернет-магазин канцелярских товаров и аксессуаров для рабочего пространства. Реализован на Bootstrap 5.3 с тёмной темой (`data-bs-theme="dark"`). Все обязательные страницы, компоненты, сетка и формы присутствуют.

## Используемый фреймворк

Bootstrap 5.3.

## Способ подключения

Bootstrap подключён **локально**, без CDN. Файлы фреймворка размещены в `vendor/bootstrap/`.

Используются:
- `vendor/bootstrap/css/bootstrap.min.css`
- `vendor/bootstrap/js/bootstrap.bundle.min.js`

`custom.css` подключается после Bootstrap и содержит только фирменные правки.

## Реализованные Bootstrap-компоненты

- `navbar` (сворачивающееся мобильное меню)
- `card` (карточки товаров)
- `btn` (разные варианты, включая `disabled`)
- `badge` (Новинка, Хит, Скидка)
- `alert`
- `modal` (заявка на консультацию, кнопка «Купить» на странице товара)
- `accordion` (FAQ на главной, характеристики на странице товара)
- `form-control`, `form-select`, `input-group`, `form-check`
- `pagination` (каталог)
- `breadcrumb` (страница товара)
- `list-group` (характеристики, контакты)
- `table` (не используется — заменён на list-group для тёмной темы)
- Bootstrap Grid: `container`, `row`, `col-12`, `col-sm-6`, `col-md-6`, `col-lg-4`, `g-3`, `g-4`

## Самостоятельные доработки

1. **Локальное подключение Bootstrap** — файлы в `vendor/bootstrap/`, CDN не используется.
2. **Тёмная тема** через `data-bs-theme="dark"` + фирменные акценты в `custom.css`.
3. **Дополнительная страница `contacts.html`** — контакты магазина и место под карту.
4. **Фильтры и сортировка в каталоге** — кнопки-фильтры по категориям и `form-select` сортировки.
5. **`accordion`** — FAQ на главной и блок «Подробнее о товаре» на странице товара.
6. **`pagination`** — в каталоге.
7. **`breadcrumb`** — навигационная цепочка на странице товара.
8. **Единый визуальный стиль** через `custom.css`: hero-блок, hover-эффекты карточек, `badge-accent`, `price`.
9. **Адаптивность** проверена на ширинах 320 / 375 / 768 / 1024 / 1440 px.
10. **Места под изображения** — блоки `.img-placeholder` и `.product-main-img` с фиксированной высотой, чтобы сетка не «прыгала».

## Как проверить

1. Открыть `index.html` — есть navbar, hero, преимущества, популярные товары, FAQ, модалка.
2. Открыть `catalog.html` — сетка карточек, фильтры, сортировка, пагинация.
3. Открыть `product.html` — фото-заглушка, цена, badge, кнопки действия, аккордеон, модалка.
4. Открыть `order.html` — форма со всеми обязательными полями.
5. Открыть `contacts.html` — контакты и место под карту.
6. Сузить окно до 375 px — navbar сворачивается в burger, карточки в одну колонку.
